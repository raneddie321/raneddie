# RanEddie — Product Studio

A premium, dark-first one-page studio website built with Next.js, React, Tailwind CSS v4 and Framer Motion.

## Included
- Responsive landing page with sticky navigation, animated hero, product bento, marquee, studio/about section, Lab and contact footer.
- Fizz Browser concept preview and product links.
- Snake Brawl artwork and the official RanEddie logo in `public/images/`.
- Metadata, Open Graph and Twitter cards.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

## Product links
- Fizz Browser: https://fizzbrowser.vercel.app/
- Snake Brawl: https://play.google.com/store/apps/details?id=com.snakebrawl.raneddie

The Fizz browser preview is an original concept mockup, not a captured product screenshot. The website avoids presenting unverified download counts or app ratings as facts.
